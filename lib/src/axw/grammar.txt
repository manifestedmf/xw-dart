For current version: AXW2.0;
[<?Text?> RP+] is a Structure Definition.
[-] is a Structure Closer. needs an example on that line for if it isn't a plural structure.
[<!Text!>] is a Caller.
[{Caller} λ] is a needed Caller.
[{Caller} Ω] is an unneeded Caller.
[{Caller}π] is a multi Caller.
[{Caller}Σ] is a single Caller.
[{Caller}π({Symbol})] is a multi Caller where symbol has to placed between every single other,
    so between each-other.
[/Symbol\] is a Reference to a single symbol.
[~/Symbols\~] is a Plural symbols.
[{Symbol}β] is a non-case specific symbol(s).
[{Symbol}α] is a case specific symbol(s).
[:{Item};] is a list of items (Caller or Symbol) which can be chosen from.
[|] is a or.
[&] is a and.
[σ  {Item}  ε] means it has to be connected (no whitespaces).
